`companion.npy` is the companion voice that Pocket TTS speaks: a [119, 1024] f32 embedding, built into the daemon.
It is the output of Kyutai's `mimi_encoder.onnx` for a 9.48 s clip of the owner's Qwen3-TTS speech, trimmed at its last pause.
